A cross-platform mobile app built with React Native that extends WaniKani's Japanese learning experience to iOS and Android. It gives access to Japanese study materials with progress tracking, review quizzes, interactive lessons and more. Built in TypeScript on the WaniKani API for a smooth, native-feeling experience on both platforms.
